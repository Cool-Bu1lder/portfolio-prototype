# READ ME

npx prettier . --write

## Commands

`npm install`
`npm run dev`
`npm run build`
`npm run preview`
`npm run astro ...`
`npm run astro -- --help`

## Installs

### Dev tools

`npm install -D -E prettier prettier-plugin-astro`
`npm install -D eslint eslint-plugin-astro`
`npm install -D typescript-eslint`
`npm install -D @tailwindcss/typography`

### Core Packages

`npx astro add preact`
`npx astro add tailwind`
`npx astro add mdx`
`npx astro add astro-expressive-code`
`npm install @expressive-code/plugin-line-numbers`
`npm install @fontsource-variable/inter`
`npm install @fontsource-variable/jetbrains-mono`
